## ドキュメントの使い方

### 開発者向け
1. まず **01_theoretical_foundations.md** で理論を理解
2. **02_technical_specifications.md** で実装詳細を確認
3. **03_detailed_design.md** で設計思想を学習

### ユーザー向け
1. **04_user_manual.md** から始める
2. 必要に応じて理論的背景を **01_theoretical_foundations.md** で確認

### 保守担当者向け
1. **03_detailed_design.md** で全体設計を把握
2. **02_technical_specifications.md** で実装詳細を確認
3. **01_theoretical_foundations.md** でアルゴリズムの数学的基礎を理解

## ドキュメントの特徴

- **完全性**: すべてのアルゴリズム、数式、仕様を網羅
- **正確性**: ごまかしやフォールバックなしの正確な記述
- **詳細性**: 実装レベルまでの詳細な説明
- **実用性**: 実際の使用例と実践的なガイド
